# Content Patterns for Simple Explanations

Use only the sections that help the reader. A short explanation should remain
short; a study guide can use the complete structure.

## Recommended document structure

1. **Cover**
   - Specific title
   - One-sentence promise
   - Audience and evidence date or scope
2. **The 60-second explanation**
   - Problem
   - Method
   - Main result
   - Central caution
3. **Why this matters**
   - The decision or question the work informs
4. **How it works**
   - Ordered steps from source material to conclusion
5. **Key concepts**
   - Plain meaning, intuition, exact definition, example, caution
6. **Results**
   - Exact values and units
   - Interpretation beside each value
7. **Uncertainty and limits**
   - What can vary
   - What is missing
   - What is descriptive rather than causal
8. **Recap and glossary**
   - Five or fewer takeaways
   - Short definitions of necessary terms
9. **Sources**
   - Local artifact names and/or human-readable external citations

## Formula pattern

For every formula:

1. Show the formula.
2. Say it aloud in ordinary language.
3. Define each symbol and unit.
4. Substitute a verified example.
5. Explain the result.
6. Name the most likely misuse.

Do not call an index a literal count. Do not turn a probability or interval
into a binary verdict unless the underlying method and user explicitly require
that decision rule.

## Statistics and uncertainty

- State the observation or resampling unit.
- State the numerator and denominator.
- Preserve genuine zero separately from missing or unavailable values.
- Explain intervals numerically and directionally.
- Describe effect sizes in context.
- Avoid p-value ceremonies, winner labels, or causal language when the analysis
  is exploratory.
- Put sparse-sample warnings in the relevant table row or result block.

## Tables

Use a table when the reader must compare repeated fields across at least three
items. Keep labels left-aligned and numeric columns aligned consistently.
Include units in headers. Use N/A for unavailable values and 0 only for a
genuine zero.

## Visual tone

Aim for calm, editorial clarity:

- consistent typography and spacing;
- strong hierarchy without oversized headings;
- restrained color;
- pale callouts for definitions, cautions, and key results;
- no decorative chart or image that fails to teach something;
- enough white space to separate ideas without inflating page count.

## Accuracy checklist

- Every number has a source or reproducible calculation.
- Every comparison uses compatible units and scope.
- Assumptions are labeled.
- Missingness is disclosed.
- Limitations appear before the final conclusion.
- External claims have readable citations.
- Word and PDF contain the same substantive content.
- No TODO, TBD, placeholder, tool token, or internal prompt remains.
